# CampCareer

Study abroad ROI explorer for comparing tuition, salary, payback period, and post-tax earning potential across US, Ireland, UK, Canada, and Australia.

## Tech Stack
Next.js, Supabase, Tailwind CSS, Vercel

## Environment Variables
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

## Run Locally
npm install
npm run dev
