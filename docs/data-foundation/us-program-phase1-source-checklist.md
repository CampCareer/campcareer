# US Programs — Phase 1 Source Checklist

Date: 2026-08-10

This checklist is a compact execution companion to `us-program-phase1-discovery.md`. Phase 2 collectors should use it before a candidate programme is allowed into the U.S. seed.

## Required programme identity

- [ ] Canonical institution ID resolved.
- [ ] IPEDS UNITID resolved where applicable.
- [ ] Exact current programme/major title from an official institution page or catalogue.
- [ ] Credential/award level explicit; not inferred from title alone.
- [ ] Official programme URL stored.
- [ ] Source-as-of date stored.
- [ ] At least one relation to the CampCareer canonical 80 programme-matching careers.
- [ ] `direct`, `common_pathway` or `related` relation reviewed conservatively.

## CIP / federal structured evidence

- [ ] Exact CIP code evidence state recorded (`verified`, `corroborated`, `unresolved`).
- [ ] CIP 2020 taxonomy used for current classification.
- [ ] IPEDS/College Scorecard used as discovery/corroboration, not as a substitute for the current marketed programme identity.
- [ ] No programme title fabricated from a CIP label.

## Accreditation / regulation

- [ ] Institutional accreditation context checked against U.S. Department of Education recognized accreditation data where publication needs it.
- [ ] Programmatic accreditation checked separately for regulated professions where relevant.
- [ ] State professional licensure/approval remains a separate fact.
- [ ] Programme→career relation does not claim automatic licence eligibility.

## International student / SEVP

- [ ] Programme-level international-student evidence checked separately from institution existence.
- [ ] SEVP school/campus status checked against DHS Study in the States when relevant.
- [ ] F-1 / M-1 context stored separately.
- [ ] SEVP certification is not treated as proof every programme is open to international students.
- [ ] Current intake/deadline is `unknown` unless a current official source states it.

## OPT / STEM OPT

- [ ] General OPT context is applicant/status-sensitive and not stored as a guaranteed programme outcome.
- [ ] STEM OPT is not inferred from programme title or broad field.
- [ ] Positive STEM designation requires an exact verified CIP and a match to the current DHS STEM Designated Degree Program List.
- [ ] DHS STEM list version/effective/check date retained.
- [ ] School accreditation/SEVP and employer requirements remain separate from the degree CIP condition.

## Location

- [ ] Programme campus/city is null unless programme-level delivery evidence exists.
- [ ] Institution address is not reused as programme location.
- [ ] SEVP main campus is not assumed to be the programme delivery campus.
- [ ] Online/hybrid delivery is not assigned a physical programme city without evidence.

## Scope control

- [ ] Candidate is useful for one of the canonical 80 careers.
- [ ] Existing Tier A 25-institution pool considered first.
- [ ] Tier B institution expansion has an explicit occupation-coverage reason.
- [ ] Candidate is not being added merely to increase catalogue size.
