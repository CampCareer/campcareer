## 2. Pipeline

```
official source (URL, licence, checksum, tier)
   → source_manifest.json                       (manifest.py, schemas.py)
   → parser output (raw JSONL, envelope fields)  (outside framework)
   → normalize_record                            (validation.py)
        UK → GB (raw preserved in evidence)
        unknown sentinel/"" → null (recorded in evidence)
        candidate_id = source_id:source_record_key
   → validate_record (11 rules)                  (validation.py, manifest.py, checksum.py)
   → identity_status + queues                    (identity.py)
        duplicate_review_queue.csv      (duplicate source keys, manual review only)
        unresolved_identity_queue.csv   (lineage cannot be resolved)
   → candidate package (8 files)                 (package.py, runner.py)
        data/candidates/<domain>/<country>/<date>/
```

`import_status` is always `candidate_only`; canonical import is a separate, human-approved, controlled step that this framework deliberately does not implement.

## 4. Source manifest (per official source)

Required fields: `source_id`, `country_code`, `data_domain`, `authority`, `official_url`, `retrieval_method`, `licence`, `usage_restriction`, `refresh_cadence`, `retrieved_at`, `reviewed_at`, `content_type`, `checksum` (`sha256:<64 hex>`), `file_size`, `parser_version`, `candidate_schema_version`, `raw_storage_tier` (`t1`/`t2`/`t3`), `notes`.

Policy points:

- `country_code` must be canonical (`AU/CA/IE/GB/US`); `UK` fails validation (alias only, normalize at record level).
- `raw_storage_tier: t3` (licence/ToS restricted) emits a **warning, not a block**: raw data must not be stored; Git keeps only manifest + checksum + retrieval instruction. The example package `geography/GB` demonstrates a tier-3 source.
- `source_id` must match `^[a-z0-9][a-z0-9\-]{2,63}$` and must not contain `:` (candidate_id separator).
- checksum is validated for format; raw files are never stored inside this framework, so re-verification is a separate controlled step.

## 5. Candidate envelope

```
candidate_id              # deterministic: source_id:source_record_key (never a random UUID)
candidate_schema_version  # 1.0.0
data_domain               # geography / visa / programme / institution / employer / finance / housing
source_id                 # from manifest
source_record_key         # official source identifier (e.g. subclass-482, QHA101, CAO code)
country_code              # canonical alpha-2 (AU/CA/IE/GB/US)
observed_at / retrieved_at / reviewed_at
parser_version
payload                   # domain facts
evidence                  # official_url, raw values, alias/unknown-normalization trail
validation_status         # valid / valid_with_warnings / invalid / blocked
identity_status           # new_candidate / duplicate_review / unresolved
import_status             # always candidate_only
```

Builder-computed fields (`candidate_id`, `validation_status`, `identity_status`, `import_status`) are never trusted from input; the parser only provides the rest.

## 6. The 11 validation rules

| # | rule | effect |
|---|---|---|
| 1 | `manifest_valid` | source manifest valid; tier-3/parser drift → warn; malformed → block whole package |
| 2 | `file_checksum` | checksum format-valid; bad → block whole package |
| 3 | `schema_valid` | envelope + payload/evidence object shape |
| 4 | `required_fields` | non-empty required fields + schema version |
| 5 | `country_code_normalization` | invalid code → fail; UK on raw input → fail (must normalize); non-canonical ISO → warn |
| 6 | `date_valid` | ISO 8601 UTC observed/retrieved/reviewed |
| 7 | `source_lineage` | source_id declared in manifest; key non-empty |
| 8 | `duplicate_source_key` | duplicate `(source_id, source_record_key)` → invalid + review queue (never auto-delete) |
| 9 | `candidate_identity` | no random UUID candidate_id; must equal `source_id:source_record_key` |
| 10 | `null_unknown` | unknown sentinels / empty string must be `null` (no 0 substitution) |
| 11 | `import_safety` | `import_status` must be absent (pre-build) or `candidate_only`; no `production_imported`/`canonical_uuid`/`auto_merged` in payload |

Package status = worst per-record status (`blocked > invalid > valid_with_warnings > valid`); manifest/checksum failure forces `blocked`.
