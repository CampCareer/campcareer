## 4. Safety gates

The apply tool `apply.py` enforces, in order:

1. **Country allowlist** — only `AU` accepted; any other country code rejected with `SafetyGateError`.
2. **Confirmation token** — must equal `APPLY_AU_GEOGRAPHY_42`.
3. **Plan fingerprint** — SHA-256 of the plan file and the in-file `plan_checksum` must both match the approved values.
4. **Plan content** — exactly 1 country action, 9 region actions, 32 city actions; counts `INSERT=41`, `NOOP=1`; no `UPDATE/DELETE/UPSERT`; city names must exactly equal the 32-name approved set.
5. **Pre-state verification** — inside the transaction: AU country count = 1, AU region count = 0, UK/GB country presence checked.
6. **Deterministic UUIDs** — every row id derived via `generate_uuid(candidate_key)`; no arbitrary UUIDs.
7. **Post-insert verification before COMMIT** — AU regions = 9, AU cities = 51, orphan cities = 0, duplicate canonical identities = 0.
8. **Automatic ROLLBACK** — any failure inside the transaction rolls back; no partial commit.
